
# ⚠️ DIRECTORY MOVED

The frontend files have been reorganized for better structure.

## New Locations:

- HTML files: `/frontend/pages/`
- CSS files: `/frontend/styles/`
- JS files: `/frontend/scripts/`

## For Development:

The backend still serves files from this `static/` directory for backward compatibility.
However, you should edit files in the new `/frontend/` directory.

## Files in this directory are now deprecated and will be removed in a future version.

See `/STRUCTURE_GUIDE.md` for complete documentation.
